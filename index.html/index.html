Key And Relevant points About Web development

  1. Create a folder, then open your editor.
  2. open the folder you created.
  3. Create three files;html,css and js files.
  4. Write your html code to structure your web page.
  5. Shift to css file and write your css code to beautify your web page.
  6. Shift to js file,write your js code for interactivity with the web page
  7. Run your code and debug for any errors that may exist.
  8. If no buggs push it to your github repository.
  9. Then you deploy your project in git by following some guidelines set by git.
